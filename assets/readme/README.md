# README artwork

The README uses custom chartreuse, warm ivory, and charcoal artwork.

| Asset | Purpose |
|---|---|
| `hero.webp` | Animated brand header; the destination indicator moves while the full message stays visible |
| `hero-static.webp` | Static header selected for reduced-motion preferences |
| `claude-folders.webp` | Illustrative Claude Code folder-selector mockup |
| `codex-folders.webp` | Illustrative Codex project-sidebar mockup with an explanatory folder inset |
| `setup-flow.webp` | Discover, choose, configure, and launch diagram |
| `setup-flow-mobile.webp` | A larger-type, two-column diagram for narrow screens |

The mockups use fictional agents and example local paths. They illustrate the workflow. Exact app layouts, available controls, and effective permissions depend on the installed version and configuration. The native guides and verification record carry setup instructions and evidence.

Display typography uses [Space Grotesk](https://github.com/floriankarsten/space-grotesk). The app mockups use system interface typography.
